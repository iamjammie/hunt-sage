Run this hunt: the five-line checklist
  1. Write the hypothesis on the hypothesis card with scope, success and failure criteria and the time-box above.
  2. Confirm each telemetry source listed at the top is actually present for the window you care about (a query on a missing log is not a negative result).
  3. Run the steps in order; stack first, then look at the long tail. Record every false positive you classify.
  4. Triage with the table above; escalate using the criteria, hand IR the hand-off template.
  5. Close with the hunt report: findings, gaps, tuning notes, and the detection or hardening ticket that makes this hunt unnecessary next time.
